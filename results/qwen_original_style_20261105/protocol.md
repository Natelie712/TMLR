This preregistered configuration evaluates all seven existing behaviors and all three existing splits. All scientific artifacts are English. No previous outputs are replaced. The official test is an exploratory fixed benchmark.

The last-token update is h + inverse(project(h)+s*d) - inverse(project(h)). All methods use the same decoder block18 output, final real token, question, target, prompt and next-token scorer. Linear is the unchanged CAA vector construction/scaling with an explicitly modified last-token scope. Curveball has no per-token displacement matching or Linear-anchored correction. Weight1 is the full polynomial update at the selected fixed parameters; weights0/0.5 are ablations. Native strengths are the prior signed fit-only parameters, not new alpha selection. They are not equal-displacement claims.
